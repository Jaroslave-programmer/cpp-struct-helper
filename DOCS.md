# Документация API модуля `extension.js` (сгенерировано по JSDoc)

## Константы
* **`DEFAULT_CPP_VALUES`** (`Map<string, string>`) — хеш-таблица сопоставления стандартных типов C++ (`int`, `long`, `size_t`, `double`, `bool`, `char`, `std::string`) и их начальных значений по умолчанию.

## Функции

### `getDefaultValueForType(cppType)`
Определяет значение по умолчанию для заданного типа данных C++. Проверяет наличие типа в `Map`, а также автоматически возвращает `nullptr` для любых типов-указателей (`*`).
* **Параметры:** `cppType` (`string`) — строковое представление типа C++.
* **Возвращает:** `string` — начальное значение для списка инициализации конструктора.

### `capitalizeIdentifier(fieldName)`
Преобразует первую букву имени поля в заглавную и очищает крайние символы подчеркивания для генерации имен методов `get...` и `set...`.
* **Параметры:** `fieldName` (`string`) — исходное имя поля класса.
* **Возвращает:** `string` — отформатированный идентификатор.

### `parseCppFields(rawText)`
Выполняет построчный разбор выделенного текста. Отфильтровывает комментарии и дубликаты имен полей с помощью структуры `Set`.
* **Параметры:** `rawText` (`string`) — выделенный пользователем текст в редакторе.
* **Возвращает:** `Array<{type: string, name: string, defaultVal: string, capName: string}>` — массив объектов с описанием полей.

### `buildCppClassCode(className, fields)`
Формирует итоговый код C++ класса (секцию `private`, конструктор по умолчанию, конструктор с параметрами, геттеры и сеттеры).
* **Параметры:**
  * `className` (`string`) — имя создаваемого класса.
  * `fields` (`Array<Object>`) — массив разобранных полей.
* **Возвращает:** `string` — готовый C++ код класса.

### `buildControlBlock(kind, paramInput)`
Динамически строит управляющий блок `for` (с произвольным шагом) или `switch-case` (с произвольным числом веток `case`).
* **Параметры:**
  * `kind` (`string`) — `'for'` или `'switch'`.
  * `paramInput` (`string`) — строка параметров, введенных пользователем через запятую.
* **Возвращает:** `string` — сгенерированный блок кода C++.

### `makeHeaderGuardMacro(filePath)`
Преобразует имя файла в формат макроса препроцессора C++ (например, `my_file.h` -> `MY_FILE_H_`).
* **Параметры:** `filePath` (`string`) — путь к текущему открытому файлу.
* **Возвращает:** `string` — имя макроса.

### `activate(context)` / `deactivate()`
Стандартные функции жизненного цикла расширения VS Code. Регистрируют команды в `context.subscriptions`.
